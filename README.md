# Junbert Advincula — Student Portfolio

A responsive one-page student portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout and IT / terminal-style visual design (dark slate, cyan and green accents, monospace headings)
- `script.js` — mobile navigation, active section links, and current year

## Preview locally
Open `index.html` in a browser, or open the folder in Visual Studio Code and use a local preview extension.

## Before publishing
1. Replace `your.email@example.com` in `index.html` with your real professional email.
2. Check the About and Skills sections and edit them to accurately reflect your current experience.
3. Add screenshots and working links for your actual projects where available.
4. Confirm you have permission to publish all images and content.

## Publish with GitHub Pages
1. Create a **public** repository named `portfolio` on GitHub.
2. Upload the contents of this folder (not just the ZIP). Keep `index.html`, `style.css`, and `script.js` at the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for publishing and open the public link shown in Pages settings. It usually looks like `https://YOUR-USERNAME.github.io/portfolio/`.
6. Test the published link on your phone and in a private browser window.

The project summaries are starter text based on topics discussed previously. Edit them to match the work you actually completed before submitting.
